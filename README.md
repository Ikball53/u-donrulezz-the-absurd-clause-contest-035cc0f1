# The Absurd Clause Contest — entry

`main.py` writes a single original English sentence to `/output/entry.txt`:
one clause that reads like genuine terms-of-service boilerplate — numbered
section, "hereby", "perpetual, royalty-free license" — until the thing being
licensed quietly turns absurd. The legalese never breaks character; the joke
is entirely in what the User is supposedly agreeing to hand over.
